# Roadmap — How I Start a Build

1. Define intent + constraints in `docs/SYSTEM_CHARTER.md` before opening Copilot.
2. Sketch the system in words: signal → parameter → behavior, one sentence each.
3. Build the smallest working version — HiDPI canvas + loop + one signal captured.
4. Iterate through visible tests: move the input, watch the behavior, adjust one variable at a time.
5. Add further signals or behaviors only after the first one is fully legible.
6. Deploy early, even an ugly version, so the live link exists from day one.
7. Polish only after the meaning is legible — visuals, easing, and color come last.
8. Log every direction change in `process/changelog.md` as it happens, not at the end.
